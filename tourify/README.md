# Tourify

Web de viajes: explora países, ciudades y lugares por categoría. Sitio estático (HTML, CSS y JavaScript), sin servidor ni base de datos.

- `index.html` · inicio, selector de país y filtro por categoría
- `pais.html?paisId=N` · ciudades y lugares de un país
- `detalle.html?id=N` · ficha de un lugar
- `datos.js` · todos los datos (países, ciudades, categorías, lugares)

Para verlo en local basta con abrir `index.html` en el navegador.
